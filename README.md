# StudyHub – Your Personal Study Space

## Project Overview
StudyHub is a student-focused task management website designed to help students organize their study activities, manage tasks, and monitor their study progress through a simple and user-friendly interface.

## Project Objective
The objective of this project is to apply the web development concepts learned during the internship by developing a responsive and interactive website using HTML, CSS, and JavaScript. The project also demonstrates the use of Git, GitHub, and GitHub Pages for version control, repository management, and deployment.

## Technologies Used
- **HTML5:** Structures the website content.
- **CSS3:** Provides styling, layout, and responsive design.
- **JavaScript:** Adds interactive functionality to the website.
- **Git:** Tracks changes in project files.
- **GitHub:** Hosts the project repository.
- **GitHub Pages:** Publishes the website online.

## Main Features
- Simple and user-friendly homepage.
- Navigation menu with Home, My Tasks, and About sections.
- Study task input field.
- Task category selection.
- Task search and filtering interface.
- Summary cards for total tasks, completed tasks, pending tasks, and progress.
- Responsive layout designed for different screen sizes.
- Interactive task management interface.
